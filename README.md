# homebrew-tono

Homebrew tap for the [tono](https://github.com/tono-lang/tono) CLI.

## Install

```sh
brew install tono-lang/tono/tono
```

## Update

```sh
brew upgrade tono
```

The formula in `Formula/tono.rb` is updated automatically by tono's release
workflow on every tagged release; it is not meant to be edited by hand here.
